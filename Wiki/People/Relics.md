# Relic bosses

From **cycle 2**, a domain lord’s chamber is sometimes empty. What’s left behind can wake up hungry — a **relic**, not a lord. About three in ten empty chambers, and **at most two** relics per cycle.

| Relic |
| --- |
| Pale Bride |
| Mirror Queen |
| Empty Confessional |
| Chalice That Never Empties |
| First Altar Stone |
| Hoardheart Dragon |
| Drowned Saint |

Clear them like any boss (defeat or satisfy). Each drops a trophy piece. They’re sacred objects the tower keeps — not members of the clergy.
