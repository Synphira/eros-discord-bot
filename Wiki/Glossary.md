# Glossary

| Term | Meaning |
| --- | --- |
| **Biome** | A themed stretch of rooms (milking barns, masquerade, and so on) |
| **Burden** | Cycle torment chosen on floor 1 (+25% LP); up to three, then locked until clear |
| **Chimera** | Two hybrid forms fused together |
| **Codex** | Your journal of lore fragments (`/codex`) |
| **Curse** | A lasting brand; raises Threat |
| **Cycle** | What starts after you clear floor 35 — harder climb, better payouts |
| **Defeat** | 0 Defiance → floor 1, new curse, ordinary gear usually gone |
| **Defiance** | Will meter; drained when you climax at full lust |
| **LP** | Lust Points — spendable currency that also feeds Threat |
| **Living gear** | Clingy cursed equipment; survives defeat |
| **Mark** | Permanent tattoo or piercing from Syn |
| **Oath** | Extra torment mid-climb (+10% LP); up to two |
| **Relic** | Boss made from a sacred object (cycle 2+) |
| **Season** | Holiday window that renames pests and leans the tower |
| **Submission stance** | Eager → Resistant attitude chosen at create; persists. High Sub = hotter lust hits, easier Satisfy, bonus Submit LP. Low Sub = softer lust hits, harder Satisfy |
| **Threat** | Difficulty and lust pressure from LP and curses |
| **Trophy** | Boss-clear souvenir; one equipped; lost on defeat |
