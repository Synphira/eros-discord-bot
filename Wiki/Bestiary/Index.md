# Bestiary

Hallway monsters come in typed pools. Holiday seasons give them **aliases** — same fight, festive name. There are well over a hundred named pests in the base roster.

Bosses and relics are listed under [People](../People/Index.md), not here.

## Types

| Type | Flavour | Note |
| --- | --- | --- |
| **Beast** | Animal instinct | — |
| **Demon** | Otherworldly lust | — |
| **Slime** | Soft, shapeless, clingy | — |
| **Undead** | Corpses and spirits | — |
| **Plant** | Hungry flora | — |
| **Mimic** | Things that were furniture a moment ago | — |
| **Clown** | Carnival pests | Only if **Clowns** is on in `/options` |
