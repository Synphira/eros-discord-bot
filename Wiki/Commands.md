# Commands

Slash commands and the `e,` prefix (`E,` also works) share the same handlers.

Buttons belong to whoever opened the panel. Pressing a button **edits** that message; typing a command sends a **new** one.

## Getting started

| Slash | Prefix | What it does |
| --- | --- | --- |
| `/help` | `e,help` | Command list, tutorial, support link |
| `/create` · `/start` | `e,create` · `e,start` | Create your delver |
| `/status` | `e,status` | Sheet, Threat, burdens, bonuses, conditions, seasonal treats |
| `/name` | `e,name [name]` | Set or change your name |
| `/restart` | `e,restart` | New delver body; keep titles, achievements, progress |
